## 4. Config Bausteine (kb-cat/config-functionblock/)

[BELEGT] https://www.loxone.com/dede/kb-cat/config-functionblock/

Dies ist die umfangreiche Referenz aller Programmbausteine. **Ca. 357 einzelne Bausteine** sind hier dokumentiert.

### Kategorien von Bausteinen (Auswahl)

[BELEGT] Die Bausteine sind organisiert in logischen Gruppen:

- **Logische Bausteine:** Und, Oder, Nicht, Exklusiv ODER, etc.
- **Vergleiche:** Gleich, Ungleich, Größer oder gleich, Kleiner oder gleich, Analogkomparator, etc.
- **Mathematische Bausteine:** Addierer, Subtrahierer, Multiplizierer, Dividierer, Modulo, etc.
- **Speicher:** Merker, Analogspeicher, Zähler (Auf/Abwärts-Zähler, Aufwärtszähler), etc.
- **Zeit-Bausteine:** Schaltuhr, Monoflop, Verzögerung (Ein-, Ausschalt-, Ein- und Ausschalt-), Wecker, etc.
- **Regler:** PI-Regler, PID-Regler, 2-Punkt-Regler, 3-Punkt-Regler, Heizkurve, etc.
- **Ein-/Aus-Elemente:** Taster, Schalter, Auswahltaste, Tastschalter, Treppenlicht-Schalter, etc.
- **Beschattung:** Automatikjalousie, Dachfenster Beschattung, EIB Beschattung, etc.
- **Beleuchtung:** Lichtsteuerung, Dimmer, Konstantlichtregler, Hotel Lichtsteuerung, etc.
- **Heizung/Klima:** Heizungsmischer, Raumlüftungssteuerung, AC-Steuerung, Fan Coil Steuerung, etc.
- **Sicherheit:** Alarmanlage, Benachrichtigung, Brand- und Wassermeldezentrale, SIA DC-09, etc.
- **Spezialanwendungen:** Poolsteuerung, Saunasteuerung, Wallbox Manager, IR-Steuerung, etc.
- **Kommunikation:** BACnet, Netzwerk Interkommunikation, Event Database Connector, etc.
- **Audio:** Audio Player, Music Server Zone, Multiroom Audio (Zenrale), etc.

## 5. Vergleich: loxone-config vs. config-functionblock

[BELEGT] https://www.loxone.com/dede/kb-cat/loxone-config/  
[BELEGT] https://www.loxone.com/dede/kb-cat/config-functionblock/

### Bausteine in loxone-config, die NICHT in config-functionblock stehen

**Analyseergebnis:** [BELEGT] Die Kategorie **loxone-config (Bausteine)** enthält KEINE einzelnen Programmbausteine wie "Merker", "Schalter", oder "Taster".

Stattdessen handelt es sich um administrative und organisatorische Konfigurationsaspekte:

| Artikel | Charakter | Besonderheit |
|---------|-----------|--------------|
| Beleuchtungsgruppen | Konzept/Modus | Organisierung von Lichtquellen; nicht einzelner Baustein |
| Betriebsmodi | Konzept | Systemweite Betriebsmodi (Normalität, Wartung, etc.) |
| Betriebszeiten (Kalender) | Peripheriebaum-Element | Zeit-Verwaltung im Peripheriebaum, kein Baustein |
| EIB/KNX Datentypen | Kommunikations-Referenz | Datentypen für EIB/KNX-Integration |
| EIB/KNX Einleitung | Einführung | Anleitung für KNX-Anbindung |
| EIB/KNX Grundlagen | Anleitung | Konzepte für KNX-Integration |
| EIB/KNX Szenario Logik | Anleitung | Programmierungsmuster für KNX |
| EIB/KNX Szenario Visualisierung | Anleitung | Visualisierung von KNX-Systemen |
| Fidelioserver | Spezial-Integration | Hotel-Verwaltungssystem (nicht als Baustein) |
| IROOM CONTROLLER | Spezial-Integration | Raum-Controller-Integration |
| Kommunikation mit MODBUS RTU | Anleitung | Protokoll-Integration |
| Kommunikation mit MODBUS TCP | Anleitung | Protokoll-Integration |
| Kommunikation mit RS232/485 | Anleitung | Serielle Kommunikation |
| Kommunikation mit UDP | Anleitung | Netzwerk-Kommunikation |
| Korrektur | Wartung/Debugging | Fehlerbehandlung in der Config |
| Liveview / Simulation | Debugging-Tool | Testumgebung für Konfiguration |
| Logger | Datenanalyse-Tool | Datenerfassung und Auswertung |
| Messinstrument für Liveview | Debugging-Tool | Messwerte im Liveview anzeigen |
| Projektanalyse | Analyse-Tool | Projekt-Strukturanalyse |
| Projektplanung | Workflow | Planung von Projekten |
| Sicherung | Datenverwaltung | Backup/Restore-Funktionen |
| Szenario EIB Sensorik | Anleitung | Muster für EIB-Sensoren |
| To-Dos / Notiz | Projekt-Management | Notiz-System für Config |
| Tracker | Datenanalyse-Tool | Verfolgung von Ereignissen |
| Validierung | Fehlerprüfung | Syntaxprüfung und Konsistenzprüfung |
| Verbrauchszähler | Spezial-Tool | Erfassung von Verbrauchsdaten |
| Virtuelle Ein- und Ausgänge | Konzept | Verwaltung virtueller Eingänge/Ausgänge |
| Virtueller HTTP Eingang | Kommunikation | HTTP-basierte Eingänge |
| Zentral | Zentral-Funktionen | Zentrale Schalt- und Steuerbefehle |

**Fazit:** [BELEGT] Es gibt **keine eigenständigen Programmbausteine in der Kategorie loxone-config, die nicht auch in config-functionblock aufgeführt sind**. Die Kategorie loxone-config dient zur Organisation und zum Verständnis von Config-übergreifenden Konzepten.

**Zusatz-Bausteine in config-functionblock, die nicht in loxone-config erwähnt sind:** [BELEGT] Alle 357+ Programmbausteine sind nur in config-functionblock dokumentiert, da sie dort ihre detaillierte Referenzdokumentation haben.
